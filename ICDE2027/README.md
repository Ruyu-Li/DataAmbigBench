## Main evaluation inputs

The ICDE 2027 benchmark contains 1,600 queries across eight subsets.
The archived multimodel runner in Package 02 includes seven subsets
(1,400 queries). Package 01 includes a separate 200-query TAT-QA sample.
The exact TAT-QA input and run configuration used for the final main
results are still being verified.
