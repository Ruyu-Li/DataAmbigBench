# DataAmbigBench code packages

Extract the outer ZIP, then extract the three module ZIPs as needed.

1. Dataset Construction and Validation covers eight benchmark subsets, common preparation, and human-review sampling.
2. Main Evaluation, Resume and Scoring covers the four evaluation settings, multimodel runs, resumption, and subset-specific scoring.
3. Scalability, Analysis and Paper Assets covers table-size experiments, offline analysis, available tables and figures, and historical pilots.

Each module includes its own README and file manifest. This archive preserves available scripts and configurations. The module READMEs document missing source files, external input dependencies, and run versions still to be confirmed.
